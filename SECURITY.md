# Security policy

Aletheia handles sensitive material (evidence, journalists' sources, victims' messages).

## Reporting a vulnerability

Please report vulnerabilities **privately**, not in public issues:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability** and fill in the form.

Never include real case data (evidence, names, messages) in a report. Use made-up examples.

We will acknowledge your report as soon as we can and keep you updated while we work on a fix.

## Supported versions

Only the latest release receives security fixes.

## Scope

See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) for what the tool does and does not protect against.
