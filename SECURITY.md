# Security policy

Aletheia handles sensitive material (evidence, journalists' sources, victims' messages).

* **Report vulnerabilities privately** to the maintainers (add a contact address before publishing) —
  do not open a public issue with exploit details. Never include real case data in reports.
* Supported version: the latest release.
* See `docs/THREAT_MODEL.md` for what the tool does and does not protect against.
