# Aletheia (Αλήθεια)

**Παθητικό εργαλείο OSINT επιπέδου τεκμηρίωσης για δημοσιογράφους και θύματα απάτης**: Ελληνικά / English.
Τρέχει σε Windows, macOS, Linux και Android (Termux). Python 3.11+, **χωρίς εξωτερικές εξαρτήσεις**.

> English: [README.md](README.md) · Πολιτική χρήσης: [ACCEPTABLE_USE.md](ACCEPTABLE_USE.md) ·
> Ασφάλεια: [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md)

## Ποιο πρόβλημα λύνει;

Τα υπάρχοντα εργαλεία είτε «ξύνουν» (scraping) τα κοινωνικά δίκτυα (εύθραυστο και συχνά αντίθετο με τους
όρους των πλατφορμών και τον νόμο), είτε είναι δύσχρηστα και δεν τρέχουν παντού. Το Aletheia ακολουθεί άλλο
δρόμο: είναι μια **μηχανή υποθέσεων και τεκμηρίων** που δουλεύει με υλικό που έχετε δικαίωμα να κατέχετε και
παράγει κάτι που οι αρχές μπορούν πραγματικά να χρησιμοποιήσουν.

| Πραγματικό πρόβλημα | Τι κάνει το Aletheia |
|---|---|
| Τεκμήρια που δεν μπορείς να εμπιστευτείς αργότερα | Θησαυροφυλάκιο με ένδειξη αλλοίωσης: αρχεία αποθηκευμένα με βάση το hash, αλυσίδα hash στο αρχείο ελέγχου, **αυτόνομο `verify.py`** σε κάθε πακέτο |
| Οι εξαγωγές «Download your information» του Instagram αλλοιώνουν τα μη αγγλικά (τα ελληνικά εμφανίζονται ως `Î•Î»...`) | Απώλειες-μηδέν επιδιόρθωση της διπλής κωδικοποίησης UTF-8 της Meta· ασφαλής ανάγνωση τεράστιων ZIP (zip-slip, ZIP bombs) |
| «Πότε έγινε αυτή η δημοσίευση;» όταν η σελίδα έχει χαθεί ή κρύβει ημερομηνίες | Αποκωδικοποίηση χωρίς δίκτυο του shortcode → ώρα δημιουργίας (*ευρετική εκτίμηση*, σαφώς σημειωμένη) |
| Σύνδεσμοι απάτης πίσω από `l.instagram.com`, `hxxp://`, γράμματα-απομιμήσεις | Ξεδιπλώνει ανακατευθύνσεις, αποκαλύπτει «defanged» συνδέσμους, επισημαίνει domains με μικτά αλφάβητα/IDN και απομιμήσεις επωνυμιών (με υποστήριξη ελληνικών και λατινικών) |
| Στοιχεία πληρωμής διάσπαρτα σε συνομιλίες | Επικυρώνει και εξάγει IBAN (mod-97), Bitcoin (Base58Check/Bech32), Ethereum (EIP-55), TRON, τηλέφωνα (E.164, ελληνικοί κανόνες), email, ονόματα χρήστη |
| «Είναι απάτη αυτό το μήνυμα;» | Διαφανείς, εξηγήσιμες ενδείξεις (πακέτα κανόνων EN + EL που μπορείτε να επεκτείνετε): υποδείξεις, όχι ετυμηγορίες |
| Παράδοση υπόθεσης στη Δίωξη Ηλεκτρονικού Εγκλήματος, σε δικηγόρους ή εκδότες | Δίγλωσσο πακέτο (αναφορές EL + EN), προφίλ *παράδοσης* (πλήρες) και προφίλ *δημοσίευσης* (με συγκαλυμμένα προσωπικά δεδομένα) |
| Εργαλεία που χαλούν σε Windows, Android ή σε ελληνικά ονόματα αρχείων | Το `aletheia doctor` ελέγχει το πραγματικό σύστημα αρχείων· ο κοινόχρηστος χώρος του Termux απορρίπτεται με εξήγηση |

## Τι ΔΕΝ κάνει σκόπιμα

Καμία σύνδεση ή scraping στο Instagram ή σε άλλη πλατφόρμα, καμία αναγνώριση προσώπου, καμία αναζήτηση σε
διαρροές δεδομένων, κανένα «hack-back». Η επικοινωνία με τον διακομιστή ενός στόχου απαιτεί ρητή επιλογή.
Δείτε την Πολιτική Αποδεκτής Χρήσης.

## Εγκατάσταση και εκτέλεση

```bash
# Επιλογή 1: ένα αρχείο (χτίστε το μία φορά, αντιγράψτε το οπουδήποτε υπάρχει Python 3.11+)
mkdir -p dist/app && cp -r src/aletheia dist/app/
python -m zipapp dist/app -m aletheia.cli:main -c -o aletheia.pyz
python aletheia.pyz doctor

# Επιλογή 2: από τον πηγαίο κώδικα
PYTHONPATH=src python -m aletheia doctor

# Επιλογή 3: pip (εγκαθιστά την εντολή `aletheia`)
pip install .
```

**Termux (Android):** `pkg install python` και μετά όπως παραπάνω. Κρατήστε τον φάκελο δεδομένων στον ιδιωτικό
αρχικό φάκελο του Termux (προεπιλογή). Ποτέ στο `/sdcard`: το `doctor` και το `case new` αρνούνται τον
κοινόχρηστο χώρο.

Γλώσσα: `--lang el|en`, ή `ALETHEIA_LANG=el`, αλλιώς από τις ρυθμίσεις του συστήματος.

## Γρήγορη εκκίνηση

```bash
aletheia aup                                   # διαβάστε την πολιτική
aletheia case new --title "Ψεύτικο SMS courier" --purpose victim-report --accept-aup
aletheia add CASE --file messages.txt          # ή --text "..." / --stdin
aletheia ig-export CASE instagram-export.zip   # η δική σας εξαγωγή δεδομένων Meta (JSON)
aletheia triage --case CASE                    # εξηγήσιμες ενδείξεις απάτης
aletheia domain CASE evil-shop.top             # έλεγχος απομίμησης + δεδομένα καταχώρισης RDAP
aletheia capture CASE https://evil-shop.top --confirm-active   # επικοινωνεί με τον διακομιστή: η IP σας είναι ορατή
aletheia correlate CASE                        # συνδέσεις μεταξύ τεκμηρίων
aletheia case export CASE --out handover.zip --zip             # αναφορές EL + EN, τεκμήρια, αρχείο ελέγχου
aletheia case export CASE --out publish --profile publication  # συγκαλυμμένα προσωπικά δεδομένα
```

Βοηθητικές εντολές χωρίς κατάσταση: `aletheia extract --text "..."`, `aletheia ig-id <shortcode-ή-URL>`.
Προσθέστε `--json` για έξοδο που διαβάζεται από μηχανή. Κωδικοί εξόδου: `0` επιτυχία, `2` χρήση, `3` μη έγκυρα
δεδομένα, `4` θησαυροφυλάκιο/ακεραιότητα, `5` δίκτυο, `70` εσωτερικό σφάλμα, `77` άρνηση λόγω πολιτικής.

## Επαλήθευση πακέτου (για παραλήπτες)

Εξαγάγετε το `verify.py` από το πακέτο και εκτελέστε `python verify.py handover.zip`: χρειάζεται μόνο Python
3.6+ και ελέγχει το hash κάθε αρχείου και ολόκληρη την αλυσίδα του αρχείου ελέγχου. **Κρατήστε την «κεφαλή του
αρχείου ελέγχου» (audit head) σε ανεξάρτητο μέρος** (email, δημοσίευση, χρονοσφραγίδα): αυτή αποδεικνύει ότι το
πακέτο υπήρχε σε αυτή τη μορφή εκείνη τη στιγμή.

## Ανάπτυξη

```bash
PYTHONPATH=src:tests python -m unittest discover -s tests -v     # 250+ τεστ
python tools/coverage_report.py --show-missing                   # κάλυψη με μόνο την τυπική βιβλιοθήκη
```

Τα πακέτα κανόνων (`src/aletheia/packs/*.toml`) και η λίστα επωνυμιών είναι απλά δεδομένα: οι συνεισφορές είναι
ευπρόσδεκτες, ιδίως για νέες χώρες. Τα ελληνικά πακέτα τρέχουν σε κείμενο χωρίς τόνους και με το τελικό σίγμα
ενοποιημένο, οπότε γράφονται χωρίς τόνους.

## Περιορισμοί (v0.1)

* Δεν υπάρχει ακόμη κρυπτογράφηση σε αδράνεια: χρησιμοποιήστε κρυπτογράφηση ολόκληρου δίσκου. Δεν υπάρχει
  ενσωματωμένη χρονοσφραγίδα RFC 3161.
* Έχει δοκιμαστεί σε Linux· τα Windows/macOS/Termux καλύπτονται από τεστ προσομοίωσης και ένα CI που πρέπει
  ακόμη να εκτελεστεί.
* Η δομή της εξαγωγής του Instagram δεν είναι δημόσιο συμβόλαιο: η ανάγνωση είναι ανεκτική αλλά ίσως χρειαστεί
  ενημερώσεις.
* Η επικύρωση τηλεφώνων είναι αυστηρή μόνο για την Ελλάδα· δεν υπάρχει σκόπιμα αναζήτηση BIC/τράπεζας για IBAN.
* Οι γραμμές «usage» του `argparse` παραμένουν στα αγγλικά (όλα τα υπόλοιπα μηνύματα είναι μεταφρασμένα).
